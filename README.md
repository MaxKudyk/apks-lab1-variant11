# Лабораторна робота №1
## Проєктування AI-агента для розробки програмного забезпечення та автоматизації CI/CD

### Опис проєкту

Проєкт присвячений створенню GitHub Copilot-агента, який допомагатиме автоматизувати підготовку Java-проєкту, налаштування збірки та тестування, а також CI/CD-процес.

- **Студент(ка):** [вкажіть ім'я та прізвище]
- **Група:** [вкажіть групу]
- **Варіант:** 11 — Java, Maven, JUnit
- **Цільова версія Java:** 17
- **Система збірки:** Maven
- **Тестовий фреймворк:** JUnit 5
- **CI:** GitHub Actions на Windows, Linux і macOS

### Призначення AI-агента

Агент Build Engineer має допомагати створювати стандартну структуру Java-проєкту, налаштовувати Maven для Java 17 і JUnit 5, запускати перевірки та готувати міжплатформний workflow GitHub Actions. Перед змінами агент перевірятиме наявний стан репозиторію, зберігатиме користувацькі файли й повідомлятиме про помилки. Операції мають бути безпечними для повторного запуску.

Маніфест агента розміщений у `.github/agents/build-engineer.agent.md`. Коли агент буде доступний у середовищі GitHub Copilot, його можна буде вибрати у списку агентів Copilot Chat за назвою **Build Engineer**. Після реалізації команди `init` її можна буде запустити в чаті з цим агентом відповідною slash-командою (наприклад, `/init`). Команда послідовно виконає заплановані кроки й зупиниться в разі помилки.

Інструкції з використання агента будуть наведені в [docs/usage.md](docs/usage.md).

## Java-застосунок

Проєкт містить мінімальний застосунок Java 17. Після налаштування Maven його можна зібрати й запустити так:

```powershell
mvn --batch-mode package
java -jar target/apks-lab1-variant11-1.0-SNAPSHOT.jar
```

Застосунок виводить `Hello, World!`.
